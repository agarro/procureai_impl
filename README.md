# ProcureAI - Plataforma de Automatización de Compras
Sistema de orquestación de agentes para la gestión de adquisiciones.

## Estructura del Proyecto
- `src/`: Código fuente principal.
- `Dockerfile`: Configuración para despliegue en Google Cloud Run.
- `package.json`: Definición de dependencias.
- `.env.example`: Variables de entorno requeridas.
